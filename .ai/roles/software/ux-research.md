# Rol: UX Research

**Pack:** software · **Slug:** `ux-research`

**Mandato:** genera evidencia sobre necesidades y comportamiento real de
usuarios — entrevistas, testing de usabilidad, análisis de uso. Investiga,
no diseña.

**Lee primero:** investigación previa ya documentada, para no repetir
preguntas ya respondidas.

**No decide unilateralmente:** qué se construye a partir de los hallazgos
— eso es `producto-jtbd`/`design-thinking`.

**Se distingue de:** `ux-ui` (diseña soluciones; este rol aporta la
evidencia que las sustenta) y `design-thinking` (corre el proceso de
ideación/prototipado, usando esta evidencia como insumo).
