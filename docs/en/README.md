# Continuum documentation in English

The initial Continuum team works in Spanish, so Spanish remains the canonical
language for the repository. The English guides below are maintained for people
who want to evaluate, install, or contribute to the project.

Read the [language policy](../LANGUAGE_POLICY.en.md) for the source-of-truth rule,
translation freshness, and the criteria for translating specialised material.

## Start here

- [Project overview, installation, and CLI reference](../../README.en.md)
- [Contributing guide](../../CONTRIBUTING.en.md)

## Specialised documents

These documents are currently canonical in Spanish. The links below provide a
short orientation; they are not translations of research claims or results.

If you need one of these documents in English for an active contribution,
please open an issue describing the use case. We will prioritise stable,
public-safe material first.
